about=ZGeo opens a floating panel in which you can select a folder and recursively collect all supported spatial files. In the upper-right corner of the panel, an "EN" / "RU" button switches the interface between English and Russian without restarting QGIS; the selected language is saved. On the "Settings" tab, formats for search are checked; at the top, the buttons "Select All", "Reset All", "Vector Only", and "Raster Only" are available. The Excel format is disabled by default. Scanning is performed in the background: the name of the current file and the number of files found are displayed, and the search can be interrupted. The result is displayed as a list with name, relative path, format, coordinate system, feature count, and size; the list can be filtered. After scanning, the coordinate system and feature count are loaded via QGIS providers without blocking the interface. At the same time, the total volume of each dataset is automatically calculated taking into account accompanying files (SHP+DBF+SHX+PRJ+CPG and others, MIF+MID, TAB+DAT/MAP/ID/IND); a separate "Refine" button is not required. At the bottom of the window there is a status bar: progress of operations and the number of selected files. On the "Statistics" tab, charts are built showing the distribution of files by size and by format. For a selected file, you can view the coordinate system, feature count, and attribute fields or open it in Windows Explorer. The "Check Attributes" button checks the field names of vector files: if non-Latin characters are present, "Yes" is shown in the "Attribute Problems" column, otherwise "No", and for raster files — "—". After the check, the number of problem files is displayed and the "Problems Only" filter becomes available. Long-running operations can be interrupted. When exporting the file list to Excel, summary figures are added at the end of the table, and statistics by format are written to a separate sheet. After saving, Explorer automatically opens with the file selected. / ZGeo открывает плавающую панель, в которой можно выбрать папку и рекурсивно собрать все поддерживаемые пространственные файлы. В правом верхнем углу панели кнопка «EN» / «RU» переключает интерфейс между английским и русским языками без перезапуска QGIS; выбранный язык сохраняется. На вкладке «Настройки» отмечаются форматы для поиска; вверху доступны кнопки «Выбрать все», «Сбросить все», «Только вектор» и «Только растр». Формат Excel по умолчанию отключён. Сканирование выполняется в фоне: показываются имя текущего файла и число найденных, поиск можно прервать. Результат выводится списком с именем, относительным путём, форматом, системой координат, количеством элементов и размером; список можно фильтровать. После сканирования система координат и количество элементов догружаются через провайдеры QGIS без блокировки интерфейса. Тогда же автоматически вычисляется полный объем каждого набора данных с учётом сопутствующих файлов (SHP+DBF+SHX+PRJ+CPG и другие, MIF+MID, TAB+DAT/MAP/ID/IND); отдельная кнопка «Уточнить» не требуется. Внизу окна расположена статусная строка: ход операций и количество выбранных файлов. На вкладке «Статистика» строятся диаграммы распределения файлов по размеру и по формату. Для выбранного файла можно посмотреть систему координат, количество объектов и атрибутивные поля либо открыть его в проводнике Windows. Кнопка «Проверить атрибуты» проверяет имена полей векторных файлов: при наличии нелатинских символов в колонке «Проблемы с атрибутами» ставится «Да», иначе «Нет», а для растровых файлов — «—». После проверки показывается количество проблемных файлов и доступен фильтр «Только проблемные». Длительные операции можно прервать. При экспорте списка файлов в Excel в конце таблицы добавляются итоговые цифры, а статистика по форматам записывается отдельным листом. После сохранения проводник автоматически открывается с выделенным файлом.
