about=ZGeo открывает плавающую панель, в которой можно выбрать папку и рекурсивно собрать все поддерживаемые пространственные файлы. На вкладке «Настройки» отмечаются форматы для поиска; вверху доступны кнопки «Выбрать все», «Сбросить все», «Только вектор» и «Только растр». Формат Excel по умолчанию отключён. Сканирование выполняется в фоне: показываются имя текущего файла и число найденных, поиск можно прервать. Результат выводится списком с именем, относительным путём, форматом, системой координат, количеством элементов и размером; список можно фильтровать. После сканирования система координат и количество элементов догружаются через провайдеры QGIS без блокировки интерфейса. Тогда же автоматически вычисляется полный объем каждого набора данных с учётом сопутствующих файлов (SHP+DBF+SHX+PRJ+CPG и другие, MIF+MID, TAB+DAT/MAP/ID/IND); отдельная кнопка «Уточнить» не требуется. Внизу окна расположена статусная строка: ход операций и количество выбранных файлов. На вкладке «Статистика» строятся диаграммы распределения файлов по размеру и по формату. Для выбранного файла можно посмотреть систему координат, количество объектов и атрибутивные поля либо открыть его в проводнике Windows. Кнопка «Проверить атрибуты» проверяет имена полей векторных файлов: при наличии нелатинских символов в колонке «Проблемы с атрибутами» ставится «Да», иначе «Нет», а для растровых файлов — «—». После проверки показывается количество проблемных файлов и доступен фильтр «Только проблемные». Длительные операции можно прервать. При экспорте списка файлов в Excel в конце таблицы добавляются итоговые цифры, а статистика по форматам записывается отдельным листом. После сохранения проводник автоматически открывается с выделенным файлом.
