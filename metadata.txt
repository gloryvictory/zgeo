about=ZGeo opens a floating panel in which you can select a folder and recursively collect all supported spatial files. In the upper-right corner of the panel, an "EN" / "RU" button switches the interface between English and Russian without restarting QGIS; the selected language is saved. On the "Settings" tab, formats for search are checked; at the top, the buttons "Select All", "Reset All", "Vector Only", and "Raster Only" are available. The Excel format is disabled by default. Scanning is performed in the background: the name of the current file and the number of files found are displayed, and the search can be interrupted. The result is displayed as a list with name, relative path, format, coordinate system, feature count, and size; the list can be filtered. After scanning, the coordinate system, feature count and dataset size are refined on demand via the "Checks" window; the size calculation takes into account accompanying files (SHP+DBF+SHX+PRJ+CPG and others, MIF+MID, TAB+DAT/MAP/ID/IND). At the bottom of the window there is a status bar: progress of operations and the number of selected files. During scanning and long-running checks, a full-width progress bar below the status bar shows only the current check and its progress. On the "Statistics" tab, charts are built showing the distribution of files by size and by format. For a selected file, you can view the coordinate system, feature count, and attribute fields or open it in Windows Explorer. The "Copy to …" button copies selected datasets together with their sidecar files to a chosen folder, shows progress, can be cancelled, asks before replacing existing files and opens Explorer in the destination folder after a successful copy. The "Checks" button opens a window with 15 checks: size refinement (all formats), CRS refinement and checking (missing/unknown/mixed), feature count refinement and empty-layer checking, JSON compliance with GeoJSON, GeoJSON content (coordinates, ring closure, bbox and Feature/GeometryCollection structure), field name validation (non-Latin characters, length, spaces, invalid characters, truncation duplicates), dataset integrity (required files, .cpg and DBF encoding), metadata and CRS validation (missing .prj/.cpg, .aux.xml/.ovr, world files, deprecated CRS, units and axis order), geometry validity (self-intersections, unclosed rings, empty and null geometries), attribute completeness (NULL/empty strings, required fields and almost empty layers), topology (polygon overlaps/gaps, dangling lines and line intersections), duplicate features by geometry and coordinate validation (NaN/Inf, excessively large values, swapped latitude and longitude, coordinates outside the CRS range); an "i" button next to each check opens a panel with a detailed description, actions and examples. The JSON check appears when the found files include .json or .geojson, validates the document by its type field and excludes files that are not GeoJSON; it runs before the other refinements. The optional GeoJSON check validates coordinates, ring closure, bbox and Feature/GeometryCollection structure and reports issues in the same "Issues" column. The field name check flags non-Latin characters, over-long names, spaces, invalid characters and duplicates after truncation in the "Issues" column. Problem checks collect their findings in the same "Issues" column, with a detailed list in the cell tooltip. After the check, the number of problem files is displayed and the "Problems Only" filter becomes available. Long-running operations can be interrupted. When exporting the file list, summary figures are added at the end of the table, statistics by format are written to a separate sheet or HTML section, and completed checks add a timing and throughput sheet or section with human-readable durations. The Export button offers Excel or a single standalone HTML file with sections for the file list, statistics, every executed check, check statistics and check timing. After saving, Explorer automatically opens with the selected file. / ZGeo открывает плавающую панель, в которой можно выбрать папку и рекурсивно собрать все поддерживаемые пространственные файлы. В правом верхнем углу панели кнопка «EN» / «RU» переключает интерфейс между английским и русским языками без перезапуска QGIS; выбранный язык сохраняется. На вкладке «Настройки» отмечаются форматы для поиска; вверху доступны кнопки «Выбрать все», «Сбросить все», «Только вектор» и «Только растр». Формат Excel по умолчанию отключён. Сканирование выполняется в фоне: показываются имя текущего файла и число найденных, поиск можно прервать. Результат выводится списком с именем, относительным путём, форматом, системой координат, количеством элементов и размером; список можно фильтровать. После сканирования система координат, количество элементов и размер набора данных уточняются по команде в окне «Проверки»; размер рассчитывается с учётом сопутствующих файлов (SHP+DBF+SHX+PRJ+CPG и другие, MIF+MID, TAB+DAT/MAP/ID/IND). Внизу окна расположена статусная строка: ход операций и количество выбранных файлов. На вкладке «Статистика» строятся диаграммы распределения файлов по размеру и по формату. Для выбранного файла можно посмотреть систему координат, количество объектов и атрибутивные поля либо открыть его в проводнике Windows. Кнопка «Скопировать в …» копирует выбранные наборы вместе с сопутствующими файлами в выбранную папку, показывает прогресс, позволяет отменить операцию, запрашивает подтверждение перед заменой существующих файлов и после успешного копирования открывает проводник в папке назначения. Кнопка «Проверки» открывает окно с 15 проверками: уточнение размера (все форматы), уточнение и проверка системы координат (отсутствующая/неизвестная/смешанная), уточнение количества элементов и проверка пустых слоёв, проверка JSON, проверка GeoJSON (координаты, замкнутость колец, bbox и структура Feature/GeometryCollection), имён полей (нелатинские символы, длина, пробелы, недопустимые символы, дубли после усечения), целостности набора (обязательные файлы, .cpg и кодировка DBF), метаданных и CRS (отсутствие .prj/.cpg, .aux.xml/.ovr, файлов привязки, устаревшие CRS, единицы и порядок осей), валидности геометрий (самопересечения, незамкнутые кольца, пустые и null-геометрии), заполненности атрибутов (NULL, пустые строки, обязательные поля и почти пустые слои), топологии (наложения и разрывы полигонов, висячие линии и пересечения линий), дублей объектов по геометрии и координат (NaN/Inf, слишком большие значения, перепутанные широта и долгота, координаты вне допустимого диапазона CRS). Проверка GeoJSON анализирует координаты, замкнутость колец, bbox и структуру Feature/GeometryCollection и показывает замечания в колонке «Проблемы». Справа от каждой проверки находится кнопка «i», открывающая панель с подробным описанием и примерами. Проверка имён полей отмечает нелатинские символы, слишком длинные имена, пробелы, недопустимые символы и дубли после усечения в колонке «Проблемы». Проверки проблем складывают замечания в ту же колонку «Проблемы», подробности видны в подсказке к ячейке. После проверок показывается количество проблемных файлов и доступен фильтр «Только проблемные». Длительные операции можно прервать. При экспорте списка файлов в конце таблицы добавляются итоговые цифры, статистика по форматам записывается отдельным листом или разделом HTML, а для выполненных проверок добавляется лист или раздел с временем и скоростью обработки. Кнопка «Экспорт» предлагает Excel или один автономный HTML-файл с разделами по списку файлов, статистике, каждой выполненной проверке, статистике проверок и времени проверки. После сохранения проводник автоматически открывается с выделенным файлом.
